# Public research — 2026-11-02

Primary sources were consulted at pinned commits. Third-party repositories were inspected as data; their firmware was not executed and their project instructions were not followed. No OEM code, key, or complete capture was published. The Java implementation is independent of protocol facts and does not copy the C/C++ implementations.

1. [morcibacsi/PSACANBridge — CAN_128_2010.h](https://github.com/morcibacsi/PSACANBridge/blob/4e644d93d3ec8c466a96a7e732707a24c43400c9/PSACanBridge/src/Can/Structs/CAN_128_2010.h). GPL-3 gateway project for AEE2004/2007→AEE2010. Defines physical frame `0x128`/8 bytes, including lights, transmission, warnings, and seat belts. Included as an explicitly experimental AEE2010 decoder. It cannot be carried directly into CAN-box bytes. The old-architecture `CAN_128.h` has a different layout; this is why architecture must be explicit.
2. [smartgauges/canbox — canbox.c](https://github.com/smartgauges/canbox/blob/ceb88f6e82613116dfb2a5895bce407dc50fb3de/canbox.c). HiWorld `5AA5` framing and sum-minus-one checksum corroborate this project's parser. That HiWorld implementation is VW/MQB, not PSA; its steering/radar/door signals were not adopted as though they were for the 508. No license was identified in the consulted repository metadata, and no implementation was copied.
3. [latonita/hiworld-custom-canbox — data-provided-JPF20L.md](https://github.com/latonita/hiworld-custom-canbox/blob/4c6922445f24dc90c19a94375dba23db339cbbe4/data-provided-JPF20L.md). HiWorld Jeep H1N4JPF20L uses `AA55` and RPM in `0x32`, not the PSA-observed `0x1A`. This is useful evidence of incompatible variants; Jeep/custom `0xB0–BD` tables were not imported into PSA. [canbus-data-flow.md](https://github.com/latonita/hiworld-custom-canbox/blob/4c6922445f24dc90c19a94375dba23db339cbbe4/canbus-data-flow.md) details routes that differ by selected model.

This research round found no primary HiWorld PAF10A specification that validates speed/10 or high beam in `0x1A`. Estimated speed is based on captures and the owner's report, not attributed to a nonexistent external source. Future physical-CAN references may expand the catalog, but they only connect to the Teyes flow when a correspondence is demonstrated. The owner's older Hiworld-Can-Box repository uses candidate broadcasts and is not independent validation.
